# COSC 113 Vehicle Rental Lab

Beginner-friendly Java project demonstrating inheritance, the `super` keyword, method overriding, and encapsulation.

## Files

- `Vehicle.java` — parent class
- `Car.java` — child class
- `ElectricCar.java` — grandchild class
- `Main.java` — program entry point and reflection answers in comments
- `REFLECTION.md` — reflection answers in Markdown

## Run in VS Code

1. Open this folder in VS Code.
2. Make sure a Java JDK is installed.
3. Open `Main.java`.
4. Click **Run** above the `main` method.

Alternatively, from a terminal in this folder, run:

```bash
javac Vehicle.java Car.java ElectricCar.java Main.java
java Main
```
